# Cồn Xanh – bản Unity (GĐ3)

Unity 6 (6000.6.9f1), mẫu **Universal 3D (URP)**, gói **glTFast 6.18.0**.

Dự án đầy đủ nằm trên máy: `G:\UnityProjects\ConXanh`. Thư mục này lưu phần do mình viết:
- `Assets/ConXanh/Scripts` – code C# (tự dựng cảnh khi bấm Play, không cần kéo thả gì)
- `Assets/ConXanh/Resources/Models` – model GLB xuất từ bản web + bộ cây cỏ CC0
- `Assets/ConXanh/Resources/Shaders` – shader nước, địa hình, bóng mờ
- `Packages/manifest.json` – có thêm glTFast

Mở dự án mới từ đầu: tạo project Universal 3D, chép `Assets/ConXanh` vào `Assets/`, thêm dòng glTFast vào `Packages/manifest.json`, mở Unity rồi bấm Play.
